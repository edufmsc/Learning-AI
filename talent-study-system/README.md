# 人才發展管理師學習作業系統

此目錄為人才發展管理師 Day1–Day5 學習系統的正式 GitHub 工作區。

## 架構原則

- GitHub Pages：網站程式、PWA、題庫邏輯、學習介面、版本管理。
- Google Drive：原始教材、完整版 TTS 腳本、MP3、大型私人內容與備份。
- 使用者情境：工作快複習、深度學習、題庫與模考、有聲課程、學習分析。
- 教材來源：所有教學篇、卡片與題目必須可追溯至 Day、章節、原始 PDF 頁碼／教材投影片。
- 隱私：原始課程講義不直接公開到 public repository；網站程式與私人教材分離。

## 發布流程

1. `talent-study-system` branch 為整合與驗收分支。
2. 完成 UX、教材來源、桌面提醒與 GitHub Pages 實機驗收後再合併到 `main`。
3. 後續修改直接由 GitHub 版本管理，不再以 v8、v9 資料夾維護。
